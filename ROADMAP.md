# Usage Guard roadmap

## v1.0 alpha — foundation

- [x] Keep normal work in the current Codex session
- [x] Separate core policy from presentation
- [x] Add Rust core workspace and policy fixtures
- [x] Add Tauri visual companion scaffold
- [x] Keep visualizer non-critical/read-only
- [ ] Port task-state schema + atomic persistence to Rust
- [ ] Port repository inspection and verification discovery
- [ ] Port compression + local usage adapters
- [ ] Ship signed/prebuilt visual companion assets

## v1.0 beta — distribution and proof

- [ ] Single-command installer using release assets
- [ ] Windows/macOS/Linux release matrix
- [ ] Automatic update channel with explicit user control
- [ ] Benchmark corpus + published baseline/guarded results
- [ ] Quick-start walkthrough with screenshots
- [ ] 60–90 second README demo
- [ ] Troubleshooting/FAQ docs
- [ ] Stable extension capability interface

## v1.0 — stable

- [ ] Rust core is default runtime
- [ ] Python compatibility layer removable/optional
- [ ] Native installers/packages
- [ ] Versioned state migrations
- [ ] Documented privacy/security model
- [ ] Reproducible release checksums
- [ ] Public contribution guide and issue templates

## Intentionally not prioritized

- mandatory cloud telemetry
- mandatory Browser Use Cloud
- automatic model switching
- multi-agent fan-out by default
- a large plugin marketplace before the core contracts stabilize
- decorative dashboards that do not improve task execution
